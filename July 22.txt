		Maven : Is Java Application Build Tool 
		
			- Compile/UnitTest/Create Artifacts 
			
			
			- pom.xml 						# Project Object Model 
			
				- This defines the properties of the Maven Build 
				- It defines all the plugins and dependencies required to build an application.
				
				Build Environment: 
					
						jdk,maven 
						
			- maven goals :					# set of actions 
			
				- mvn compile			# Compile the source code 
				- mvn test 				# Compile the source code & perform automate unit testing 
				- mvn package			# Compile the source code, perform automate unit testing & Create artifacts in the target folder
				- mvn clean 			# Clean-up the target folder
				
				
				Eg.: 
				
					mvn clean package
